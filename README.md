# Breathe ESG Ingestion Platform

A Django REST + React prototype for ingesting, normalizing, and reviewing enterprise emissions data from three source types before audit sign-off.

## Tech Stack

- **Backend:** Django 4.2, Django REST Framework, Simple JWT, PostgreSQL (SQLite for local dev)
- **Frontend:** React 18, Vite, Tailwind CSS v3, Axios, Lucide icons
- **Deploy:** Render.com (render.yaml included)

## Local Development

### Prerequisites
- Python 3.12+
- Node.js 18+

### Backend Setup

```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

pip install -r requirements.txt
python manage.py migrate
python manage.py seed        # creates demo tenant + analyst user
python manage.py runserver   # runs on http://localhost:8000
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev                  # runs on http://localhost:5173
```

## Data Sources

### SAP — Fuel and Procurement
Ingests a flat file CSV export from SAP transaction **SE16N** (table MSEG — Material Document Segment). Handles German-format ABAP field names (WERKS, MATNR, MENGE, MEINS, BUDAT, KOSTL, TXZ01), two SAP date formats (YYYYMMDD and DD.MM.YYYY), and volume→mass conversion using material density. Scope 1 (fuel) vs Scope 3 (procurement) is determined by keyword matching on TXZ01 (material short text).

### Utility — Electricity
Ingests a **portal CSV export** in the format produced by major UK utility supplier portals (EDF, British Gas, E.ON). Handles non-calendar billing periods (UK bills are anchored to the meter read date, not the month). Billing periods outside 25–35 days are auto-flagged. Converts kWh → kg CO₂e using DESNZ 2023 UK grid average (0.20707 kg CO₂e/kWh).

### Corporate Travel — Flights, Hotels, Ground
Ingests a **Concur TripLink CSV export**. Supports flights (with Haversine great-circle distance calculation for missing distances using IATA airport codes), train, car, and hotel stays. Emission factors from DEFRA 2023, including radiative forcing for flights (0.255 kg CO₂e/km economy class).

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/auth/token/` | JWT login (email + password) |
| POST | `/api/auth/token/refresh/` | Refresh JWT |
| GET | `/api/runs/` | List ingestion runs |
| POST | `/api/ingest/sap/` | Upload SAP CSV |
| POST | `/api/ingest/utility/` | Upload utility CSV |
| POST | `/api/ingest/travel/` | Upload travel CSV |
| GET | `/api/records/` | List emission records (filter: status, scope, source_type) |
| PATCH | `/api/records/{id}/` | Update record status + create audit event |
| POST | `/api/records/bulk-approve/` | Bulk approve selected record IDs |
| GET | `/api/records/summary/` | Aggregate summary (totals by scope and status) |

## Deployment (Render)

The `render.yaml` in the root configures:
1. A **PostgreSQL** managed database
2. A **Django backend** web service (with gunicorn, collectstatic, migrate, and seed)
3. A **React/Vite** static site

Required Render environment variables (auto-set by render.yaml):
- `DATABASE_URL` — injected automatically from the PostgreSQL instance
- `SECRET_KEY` — auto-generated by Render
- `CORS_ALLOWED_ORIGINS` — set to the deployed frontend URL

> **Note:** After first deploy, the seed command creates `analyst@demo.com` / `demo1234` in the demo tenant automatically.

## Architecture Notes

- **Multi-tenancy:** Thread-local middleware (`TenantMiddleware`) + custom `TenantManager` automatically scopes all queries to the logged-in user's tenant. No per-view filtering needed.
- **Audit trail:** Every status change on an `EmissionRecord` creates an immutable `AuditEvent` with the analyst's email, action, timestamp, and optional note.
- **Raw data preservation:** Every uploaded CSV row is stored verbatim in `RawRow.raw_data` (JSONField) before any normalization. Parse failures are stored as error rows, not silently dropped.
- **Emission factors:** DEFRA/DESNZ 2023 Greenhouse Gas Conversion Factors (UK). See SOURCES.md for specific values and justification.
